## 🌌 About Me

Hello! I'm **João Pedro**, a Software Developer and Systems Analysis and Development student at **Universidade de Fortaleza (UNIFOR)**, Brazil.

I have a technical background in Information Technology from the **Federal Institute of Ceará (IFCE)** and a strong interest in Software Engineering, Artificial Intelligence, Backend Development, and emerging technologies.

I'm passionate about understanding how technology works, solving complex problems, and transforming ideas into practical software solutions.

My experience includes contributing to real-world software projects, debugging existing systems, improving data processing workflows, and working with technologies such as Java, Python, Elixir, Phoenix, PostgreSQL, and Docker.

I'm particularly interested in the intersection of Software Engineering and Artificial Intelligence, exploring how intelligent tools and modern development practices can improve the way software is designed, built, and maintained.

**My philosophy:**

*Learn continuously. Build consistently. Improve relentlessly.*
